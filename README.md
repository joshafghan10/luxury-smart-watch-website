# Luxury Smart Watch Website

An interactive luxury smart watch showcase built with React, Vite, Three.js, and Tailwind CSS.

Features a 3D watch configurator, heritage timeline, craftsmanship sections, and more.

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Tech Stack

- React 19 + TypeScript
- Vite
- Three.js
- Tailwind CSS
- GSAP
